# OpenUtility

OpenUtility is a browser-first collection of fast, private developer utilities with a consistent tool experience.

## What is included
- Responsive premium homepage and tool discovery
- Dedicated tool detail experience at `tool.html?tool=<id>`
- Shareable tool entry URLs
- Tool Chains
- Developer Reference at `/docs/`
- Searchable tool reference and usage guides
- About, Privacy and Terms pages
- Custom 404 page
- PWA/offline foundation
- Open-source project page

## Product principles
- **Browser-first:** supported tools process ordinary input locally where possible.
- **Private by default:** OpenUtility does not require an account for its core tools.
- **Consistent:** tools use the same discovery, detail, sharing and workflow patterns.
- **Open:** the project source is available on GitHub and documentation is part of the product.

## Documentation
Open the developer reference at `/docs/`. It covers tool discovery, shareable links, Tool Chains, offline behavior, privacy considerations and the current tool collection.

## Privacy note
Supported tools are designed to process ordinary tool input in the browser. Review `privacy.html` for current implementation details and avoid placing secrets into URLs or shared links.
